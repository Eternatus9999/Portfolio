# Chathusha – 3D Portfolio
React + Tailwind v4 + Three.js (Vite)

    npm install
    npm run dev      # then open the URL it prints (usually http://localhost:5173)
    npm run build    # production build in /dist

- Edit your content in `src/data.js`
- Add your images to `public/images/` (see README.txt there)
- three.js is pinned to 0.152.2 on purpose: the lighting values were tuned for it.

## Controls
WASD / arrows move · Shift boost · Space jump (twice = double jump) · C crouch · E dash · M mute
Touch: drag to steer, on-screen Jump and Crouch buttons.
Jump the orange barriers, crouch under the cyan beams, dodge the red spikes.
